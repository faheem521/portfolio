About

Front-end, with a Shopify specialism

Most developers can write React. Fewer can build a Shopify embedded app that feels like it belongs inside the admin — fast, native, and correct on the edge cases. That second thing is where I spend my time.

For the last two-plus years at Tetralogicx I've shipped front-ends for live App Store apps and production SaaS platforms — turning Figma, PSD, XD, and Canva files into pixel-perfect, cross-browser interfaces and wiring them to REST and GraphQL APIs. I work TypeScript-first, build reusable component systems, and care about the parts a team feels later: clean structure, predictable state, and UI nobody has to rebuild.
